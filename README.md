# my-mail — 멀티 계정 웹메일 뷰어 (웹 콘솔)

POP/IMAP을 지원하지 않는 메일 서비스를 **웹으로 직접 접속(브라우저 자동화)** 해서
읽어오는 도구입니다. 여러 계정을 등록해 한 화면에서 관리할 수 있습니다.

## 시작하기

1. **`setup.bat`** 더블클릭 → 패키지와 브라우저 자동 설치 (최초 1회)
2. **`run.bat`** 더블클릭 → 웹 콘솔이 브라우저에서 열립니다 (`http://127.0.0.1:8765`)

서버는 `127.0.0.1` 에만 바인딩되어 **이 PC 밖에서는 접속할 수 없습니다.**
종료하려면 검은 콘솔 창에서 `Ctrl+C` 를 누르거나 창을 닫으세요.

## 웹 콘솔 사용법

화면은 세 칸입니다.

| 칸 | 내용 |
|---|---|
| 왼쪽 | 계정 목록 (초록 점 = 세션 저장됨) |
| 가운데 | 선택한 계정의 최신 메일 목록 |
| 오른쪽 | 클릭한 메일의 본문 |

- **계정 추가** — 오른쪽 위 `＋ 계정 추가`. 이메일 도메인을 보고 서비스를 자동 추천합니다.
- **메일 보기** — 왼쪽에서 계정을 클릭하면 목록을 불러오고, 메일을 클릭하면 본문이 열립니다.
- **로그인** — 세션이 없거나 만료되면 자동 로그인을 시도하고, 캡차나 2단계 인증이
  필요하면 브라우저 창이 뜹니다. 로그인을 마친 뒤 `로그인 완료됨 · 확인` 을 누르세요.
- **계정 삭제** — 계정 행의 `✕`. 저장된 비밀번호와 세션도 함께 지워집니다.
- 계정 행과 메일 행은 **키보드(Tab / Enter)** 로도 조작할 수 있습니다.

메일 목록을 처음 불러올 때는 브라우저 세션을 여느라 **3~5초** 걸리고,
이후에는 세션을 재사용해 더 빠릅니다.

## 터미널에서 쓰기

웹 콘솔이 기본이지만 기존 터미널 방식도 그대로 씁니다.

- **`console.bat`** — 번호를 골라 쓰는 터미널 메뉴
- **`mymail.bat`** — 명령줄 래퍼

```bash
python mymail.py add                     # 계정 추가
python mymail.py list                    # 계정 목록
python mymail.py fetch                   # 전체 계정 최신 메일
python mymail.py fetch --account dev     # 특정 계정
python mymail.py fetch --watch 60        # 60초마다 새 메일 감시
python mymail.py read 1 --account dev    # 1번 메일 본문
python mymail.py login --account dev     # 수동 로그인
python mymail.py inspect --account dev   # 셀렉터 튜닝용 구조 덤프
```

## 보안 / 개인정보

- 비밀번호는 `accounts.json` 에 **평문으로 저장**됩니다. 이 파일을 공유하지 마세요.
- 계정마다 별도 브라우저 프로필(`user_data/<계정ID>/`)을 써서 세션이 섞이지 않습니다.
- 메일 본문은 원격 HTML 을 그대로 넣지 않고 **텍스트로만** 표시합니다
  (외부 이미지 추적·스크립트 삽입 방지).
- 메일을 열면 서버에서 **'읽음' 처리**됩니다.

## 다른 메일 서비스 추가하기

`config.json` 의 `providers` 에 항목을 추가합니다.

| 키 | 설명 |
|---|---|
| `login_url` | **실제 로그인 폼이 있는 주소** |
| `mail_url` | 받은편지함 주소 |
| `login_redirect_markers` | 로그인 페이지임을 알려주는 URL 조각 |
| `logged_in_markers` | 로그인 성공 판정용 — 메일함 주소 조각 |
| `login_form` | `id` / `pw` / `submit` 셀렉터 (2단계 폼도 지원) |
| `row`,`sender`,`subject`,`date` | 목록 행과 각 필드 셀렉터 |
| `view.subject/header/body` | 본문 화면 셀렉터 |

`row` 나 `view.body` 를 비워두면 휴리스틱 추출기가 자동으로 추정합니다.
정확도가 떨어지면 `python mymail.py inspect --account <계정ID>` 로 실제 구조를
확인해 셀렉터를 채우세요.

## 문제 해결

**"수동 로그인은 성공인데 메일 확인은 실패"** — 로그인 판정 버그로, 수정되었습니다.
이제 "로그인 페이지가 아님" 이 아니라 **실제 메일함 주소 도달**(`logged_in_markers`)로
판정합니다. 새 서비스를 추가할 때 이 값을 꼭 채우세요. 로그아웃 상태에서 로그인 페이지가
아니라 **마케팅/가입 페이지로 튕기는 서비스**(Zoho)가 있어, 없으면 오판합니다.

`login_url` 도 반드시 실제 로그인 폼이 있는 주소여야 합니다. `https://mail.zoho.com` 은
가입 안내 페이지로 가므로 `https://accounts.zoho.com/signin?...` 을 씁니다.

**"메일을 찾지 못했습니다"** — 새 메일이 없다는 뜻이 **아니라** 목록을 긁어내지 못했다는
뜻입니다. 목록 셀렉터가 안 맞거나 SPA 렌더링이 끝나기 전에 읽어서 생깁니다.
`inspect` 로 구조를 확인해 `config.json` 을 맞추세요.

## 참고

- 네이버/다음 프리셋 셀렉터는 서비스 개편 시 바뀔 수 있습니다.
  안 맞으면 자동으로 휴리스틱 모드로 전환됩니다.
- 자동 로그인을 반복하면 캡차나 새 기기 확인을 요구할 수 있습니다.
  한 번 수동으로 처리하면 세션이 유지됩니다.
- headless 차단이 의심되면 `config.json` 의 `"headless": false`.
